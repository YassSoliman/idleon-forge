# Client-only Vite + React app, parsing in a Web Worker, no backend

ActiveOn is a static Vite + React + TypeScript single-page app served from Cloudflare Workers static assets, with no server of ours in the data path: the browser signs in to the game's Firebase, listens to the save, parses it and runs the advice engine locally. The vendored Toolbox parsers (~6 MB, 0.3–1 s per parse, and they patch built-in prototypes) run in a Web Worker so the UI never freezes and their globals stay out of our code. We chose this over Next.js (Toolbox's stack) because there is nothing to server-render, and over a backend because none is needed for login or sync and a backend would mean holding players' tokens. A Worker endpoint is reserved for later opt-in features (an "Ask why" chat, background push) only.
