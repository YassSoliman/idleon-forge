# A Worker is allowed for one job: turning in-app Suggestions into GitHub issues

Amends [ADR 0006](0006-client-only-spa-parsing-in-a-worker.md). The in-app Suggestion form posts to a small Cloudflare Worker (Turnstile-protected, rate-limited, signed-in players only) that files each Suggestion as a GitHub issue labelled `suggestion`, using a token held in Worker secrets. We chose this over a pre-filled GitHub issue link (needs every player to have a GitHub account) and over a Worker-owned database (a second inbox to watch): players need no GitHub account, and GitHub Issues stays the single tracker that Claude Code polls. The Worker never sees saves or login tokens; it receives only the Suggestion text and the attached context (Stage, versions, screen, class and level).

**Amended 2026-10-17 (M13 spec, [PR #42](https://github.com/YassSoliman/idleon-forge/pull/42)).** To prove a sender is signed in, the Worker receives only a Firebase ID token that expired at least 15 minutes earlier: it verifies Google's signature, reads the uid, and discards it, so it never holds a token that can open a save. The context it may receive is exactly the M13 `SuggestionContext`: app, parser, game and Knowledge Base versions, Stage, screen, the class, level and Verdict of the character in question, Expected Return, save age and browser family, and for "Report this" the advice's provenance (output kind, anonymous rendered text, entry, Detector and field ids, Stale and Contested flags, and for a Higher-leverage line its option id) plus the values it read when the player leaves "Attach the numbers" ticked (shown in the preview first). Never names, uid, email or the save. The Worker may also post a player's one-shot answer to a maintainer's question as a comment on that player's own Suggestion.

**Amended 2026-10-17 (spec consistency pass).** The "Report this" provenance also carries a Higher-leverage line's option id (M5 FR-18), a game-data identifier of the advice, never of the account. The version fields are the app's `BuildInfo` subset (M12 TR-4) and the save's game build (M13 TR-3).
