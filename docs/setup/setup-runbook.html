IdleOn Forge setup

Three one-time setups that let Claude Code run Cloudflare and GitHub for the Forge on its own. About 10 minutes total. Tick boxes as you go; progress is remembered in this browser.

Never paste a token or key into chat. Every value goes into the private file ~/.config/idleon-forge/ (only you can read it). When a part is done, tell Claude the phrase at the end of that part.

Part 1 · ~2 min

Cloudflare admin token (IdleOn account only)

Lets Claude create Workers, the Turnstile key, the Preview login gate and (later) DNS for your domain. Stays on your Mac; never goes to GitHub.

Part 2 · ~4 min

GitHub App: Forge Bot (agent pull requests)

Agents open PRs as this bot instead of as you, so you can approve them yourself, and the weekly parser-sync PR can trigger CI. It can only touch the idleon-forge repo.

Part 3 · ~3 min

GitHub App: Forge Suggestions (in-app Suggestions, for M13)

A separate, smaller app the Suggestions Worker uses to file issues. Kept separate so a leaked key can only touch issues, never code. Can wait until M13 is being built, but it's quick to do now.

All three parts done means Claude can create, deploy and maintain everything for the Forge without asking you to click. Delete any token or app later to revoke access instantly.
