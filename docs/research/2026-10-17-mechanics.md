## Answer

- **1. There is no general cap on claimable AFK time.** The game credits a character with the whole gap, `TimeAway.GlobalTime − TimeAway.Player`, in seconds. The only clamp in `_customBlock_AFKgains` is the **Unending Energy prayer curse, which cuts it to 10 h** (`Math.min(Time, 36E3)` when `prayersReal(2,1) > 2`). Two sanity checks exist: an unset timestamp (< 1E4), or a gap over 2E8 s (about 6.3 years), gives zero AFK time. The AFK hours are not what limits a long AFK Stretch. The limits are elsewhere: food running out (`AFKfoodsTimeRedux`), carry capacity and inventory space, and per-system stockpile caps such as the Arcade's 48 h plus up to 10 h from stamps (Toolbox `getMaxClaimTime`). (H)
- **"What raises it":** nothing, because the cap does not exist. To get more out of an AFK Stretch you add time or speed up gains. Time Candy moves `TimeAway.Player` back by the item's minutes. AFK-gain rate bonuses (`AFKgainzzALL`) include golden food "AllAFK", shrines, cards, Divinity and Summoning. ActiveOn's AFK Setup advice should therefore target carry, food and stockpile caps, and **never use Unending Energy on a character expected to be away more than 10 h**. Toolbox already raises this alert. (H)
- **2. The daily reset is a per-account countdown, `TimeAway.ShopRestock`, in seconds.** A new account starts it at **86400**, so the reset time of day is set by **when the account was created**. Each **Silver Pocketwatch** shifts it by ±15 min, depending on which slot it is used from. In play it ticks down 1 per second and is clamped at ≤ 86400. On login it is reduced by the time away (`_customBlock_AwayTimers`). Each time it reaches ≤ 0, the daily routine runs once per missed day (+86400 each pass). Some daily rewards are capped at 10 or 5 catch-up days. (H)
- **The weekly reset rides on the daily one:** each daily pass decrements `OptionsListAccount[39]` (Toolbox `WEEKLY_RESET_SHOP`). When it goes below 0, the weekly routine runs and the counter gets +7. So the next weekly reset is `ShopRestock + 86400 × OLA[39]` from the snapshot time, which is exactly what Toolbox shows. A few timers are **server-global** instead: Happy Hours and Toolbox's "server weekly" (`GlobalTime mod 604800`), and the Ballot and Meritocracy offsets. (H)
- **For ActiveOn:** read the reset from the Account State as `timeAway.ShopRestock − (now − timeAway.GlobalTime)`, as Toolbox's `hoursUntilDailyReset` does. Never assume a fixed clock time, and never assume UTC midnight. (H)
- **3. First class has a level gate: class Lv 10** (`Promotheus1`: `10 <= Lv0[0]`). **Subclass has no level gate in code.** It requires being a Warrior, Archer or Mage (class 7, 19 or 31), reaching Speccius in W2 Dessert Dunes, and holding 100 Kebab Sticks plus 50 Crabby Cakey (`Speccius1`, not consumed). **Elite class has no level gate either.** It requires being one of the six subclasses (class 8, 9, 20, 21, 32 or 33), reaching Eliteus on **W4 map 154, Outskirts of Fallstar Isle**, and killing the 10-genie Greenie Gang (`Eliteus1`). In practice the gate is reaching W4, not a level. (H)
- **This corrects an earlier finding.** The game-loop note called Eliteus a W3 step. In code, and on the wiki, Eliteus is in **W4**. Only his dialogue mentions "world 3 haters". The code agrees with the wiki's bot-generated NPC pages. (H)
- **4. There is no free stat-point allocation.** STR, AGI, WIS and LUK are computed sums (`_customBlock_TotalStats`), from equipment, star signs, bubbles, cards, stamps, family bonuses and so on. The only manual lever is **talent points** spent on the four first-tab talents: **Fist of Rage (STR), Quickness Boots (AGI), Book of the Wise (WIS), Lucky Clover (LUK)**, each "+1 Base stat per level". The `PVStatList_N` save key is a **cache of the totals** that the game writes on cloud save. It is not allocated points. (H)
- **For the Knowledge Base:** "stat allocation" advice means talent-point advice on tab 1, competing with talents like Sharpened Axe. Base all four Mod parsers' stat numbers on Toolbox's `character.stats`, which reads that cache (M).

| Ticking | In play, `ShopRestock −= 1` each second, after clamping to ≤ 86400 (@15078742). The character-select screen ticks it too (@19837762). On login, `_customBlock_AwayTimers(d)` subtracts the seconds away `d` when `0 < d < 1E8` (@6463127). | H | N.js |

## Code vs wiki

- Every mechanic above agrees between code and wiki.
- **Our own earlier note disagrees with the code.** `research/game-loop` said "Elite class: Eliteus, the Greenie Gang quest" next to W3 progression. Eliteus is in W4 (map 154), so a pure W1–3 account cannot get an elite class. Decision tickets #11 and #13 should treat elite class as out of W1–3 scope.
