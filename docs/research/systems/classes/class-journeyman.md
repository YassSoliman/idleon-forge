## Beginner line (Journeyman, Maestro, Voidwalker)

- **What it is:** a hidden four-step class line off the Beginner. Luck is main and accuracy stat for all four [C2]. It trades direct damage for utility: loot, money, cards, AFK/skill EXP, a family-wide skill buff (Maestro), and account-wide boosts plus a speedrun minigame (Voidwalker) [C8] [C1]. Wiki: Journeyman "has very low damage compared to the 3 main classes" [C8].
- **Unlocks:** each step is a quest chain with its own NPC, not a class-change menu:
  - Journeyman: Rocklyte (Froggy Fields, W1 start). Peanut chain, then "Become a Journeyman" [C4]. Not offered as a Beginner promotion in the class table [C3].
  - Maestro: Cactolyte (Djonnuttown). Skill-level gates Mining 32 / Smithing 35 / Choppin 33, then Fishing 23 / Alchemy 25 / Catching 25, then a Biggie Hours kill carrying Pete the Peanut, then "Become a Maestro" [C5].
  - Voidwalker: Nebulyte (Outer World Town). 1M Death Note kills on all W1-W3 monsters (account-wide), Chaotic Chizoar, 12M personal Green Mushroom kills, then "Become a Voidwalker" [C6]. The wiki's "Maestro level 150" gate is not in the quest data [C7].
  - None of the three quest chains is modelled by Toolbox, so ActiveOn can only infer progress from the current class [C10].
- **Scope:** per character for talents, class level, quests and the speedrun cast. Account-wide for family bonuses [C66], the Voidwalker eleven (Enhancement Eclipse to Blood Marrow, always the account's best) [C19] [C58], Left/Right Hand (from the last Maestro in save order) [C51], and the Voidwalker speedrun highscore (OptionsListAccount[158]) [C54].
- **Inputs -> outputs:** class EXP, skill levels and kills unlock steps. Talent points: tab 1 Beginner, tab 2 Journeyman, tab 3 Maestro [C11]; a Voidwalker's tab 4 comes only from speedrun portals and One Step Ahead [C12] [C13]. Output: damage/luck/money/EXP multipliers and, for the Maestro and Voidwalker, bonuses the other characters consume.
- **Goals and Milestones:** see the table below.
- **Feeds / fed by:** Death Note and kill counts (Nebulyte), skill levels (Cactolyte), Printer (Printer Go Brrr [C44]), Statues (Skilliest Statue, Voodoo Statuficiation [C48] [C62]), Cooking (Blood Marrow [C65]), Worship/Trapping (Species Epoch [C63]), Class EXP ([C47] [C61]), Star talent points ([C15]), Equinox challenge 32 (75 portals) [C54], Crystal mobs ([C39]).

- **Per-session actions:**
  - Check each cooldown cast is used: It's Your Birthday! (~23.9 h) [C38], Printer Go Brrr (~22.8 h) [C44], Void Trial Rerun (~19.4 h) [C53], Gimme Gimme / Maestro Transfusion (120 s buffs, session-time use) [C32] [C49].
  - A Maestro or Voidwalker with unspent tab points, or points not matching the build, is the main idle state (Toolbox does not compute points left; ActiveOn ports TotalTalentPoints under ADR 0010 [C11]).
  - The Hands only help characters whose skill level is strictly below the last Maestro's; flag characters that are not [C51].
- **AFK Setup implications:**
  - Fighting AFK: Sleepin' On The Job [C27], the Voidwalker family bonus (+Fighting AFK gains) [C66], Reroll Pls and Cards Galore apply to AFK [C40].
  - Enhancement Eclipse 100 points extends Sleepin' On The Job to skilling AFK [C58] [C27].
  - Maestro Transfusion trades efficiency for EXP, so cast it only when EXP matters more than output [C49].
- **Min-max by stage:** see the section after the catalogue.
- **Common mistakes:**
  - Copying a damage build onto a class with a damage penalty: Curse Of Mr Looty Booty costs up to 60% damage at level 100 [C37].
  - Spending Beginner-tab points into stat talents early instead of Sharpened Axe / Gilded Sword [C76] [C21].
  - Stacking a Maestro's Hands but leaving other characters above the Maestro's skill level, which gives them nothing [C51].
  - Treating Voidwalker tab 4 as normal talent points: class level never feeds it [C12].
  - Reading "Skillage Damage = lowest skill / 5" as the nine skills only: Toolbox also counts the class level slot [C43].

## Min-max by stage

Priority order comes from Toolbox community builds (tier 3) plus game formulas (tier 1). Build marker `*n` means a point-spend marker in the saved payload; its exact meaning is an open question.

- **W1 early (Beginner, level <= 14):** split Beginner-tab points between Gilded Sword and Sharpened Axe; ignore stat talents; add Sleepin' On The Job if AFK [C76] [C21]. (ActiveOn already has this build.) [C80]
- **W1 mid (Journeyman ~40):** tab 1 Sharpened Axe 35, Gilded Sword 20, Sleepin' 50; tab 2 Indiana Attack 50, Two Punch Man 45, It's Your Birthday! 1 [C69].
- **W1 late / W2 (Journeyman ~55):** Axe 50, Gilded 50, Sleepin' 100; Indiana 75, Two Punch 45, Birthday 1 [C70].
- **W2-W3 (Journeyman ~70 AFK):** Axe 75, Gilded 75, Clover 50, Sleepin' 100; Indiana 75, Two Punch 100, Lucky Hit 75, then Breakin', Horseshoe, Birthday, Cards Galore, Rares [C71]. Dossier-inferred order from wiki descriptions (the wiki itself does not rank, [C67] Disputed): Lucky Hit and F'luk'ey Fabrics, then Gimme Gimme and Looty Booty, then Reroll and Cards [C67]. The two sources differ: builds put damage first (Axe, Gilded, Two Punch), the wiki puts luck scaling first. Confidence M for builds on an AFK character, L on the inferred ordering.
- **W3 utility Journeyman:** Lucky Clover 100, Happy Dude 100; F'luk'ey 100, Horseshoe 100, Looty Booty 100, Birthday, Cards Galore, Rares [C72].
- **Maestro W3 (~70):** same tabs 1-2 as above with Indiana 40, Two Punch 100, Lucky Hit 100; tab 3 Coin Toss 35, Triple Jab 100, then Skillage Damage, Lucky Charms, JMan Was Better [C73].
- **Maestro W4 skilling (~100):** Happy Dude 100; Looty Booty 100, Birthday 100, Rares 100; Bliss N Chips 100, then Printer Go Brrr, Transfusion, both Hands, Skilliest Statue [C74]. Inferred (not a wiki ranking) order: Skillage Damage, Hands, Transfusion, Printer [C67].
- **Maestro late AFK (150):** Axe 160, Gilded 160, Feather Flight 160, Sleepin' 260; Two Punch 160, Chaching! 160, Rares 160, Lucky Hit 100, Horseshoe 100, Indiana 40; Skillage 160, Triple Jab 160, Bliss N Chips 160, Colloquial Containers 160, Coin Toss 35, one each Lucky Charms and Skilliest Statue, Hands [C75]. Sleepin' max beyond 100 comes from Colloquial Containers and the Lotto Skills bubble [C28].
- **W4+ Voidwalker:** unlock Void Trial Rerun, then the account-wide eleven in order of value to the account. Data-only reasoning (no community priority list could be read [C77]): Enhancement Eclipse (steps at 25 points) [C58], Exp Cultivation and Power Orb [C61] [C59], Master Of The System for multikill [C64], Eternal LUK/STR for stat and Horseshoe max [C60]. A single Voidwalker per account is enough for all of these because the account takes the best across characters [C62] [C61].
- **Per-class differences:** none beyond line stage; all four are Luck classes and AFK on Fighting uses Sleepin' only [C27]. Star talents use the shared fighting/skilling builds [C79].
