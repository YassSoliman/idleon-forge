# Islands (Fisherman) - System Dossier (M26)

Verified 2026-10-19 against Toolbox @6c37e3d, game 2.3.540. `P` = `packages/toolbox-parsers/vendor/parsers/world-2/islands.ts`; `OLA[n]` = `account.accountOptions[n]` (raw OptLacc). Scope note: this is the six World 2 "message bottle" islands. The World 5 Sailing islands are a different system (see W5+ line).

## Islands

- **What it is:** six unlockable islands run from the Deepwater Docks fisherman. Bottles (a daily currency) buy a map to each island; each island then gives a daily/weekly/AFK-fed reward loop (garbage, a weekly Random Event, crystal mobs, legendary fish, weekly stat trials, AFK-hours bonuses). [C1]
- **Unlocks:** reach the end of the Fishing docks at Fishing level 30; bottles wash up there. [C7] Per-island unlock is stored as a letter string in `OLA[169]`; the count of unlocked islands is the string length. [C2]
- **Scope:** account-wide. Everything lives in `accountOptions`; only Trash's Star Talent Book and Rando's talent book are per-character (owned by any character). [C2][C12][C17]
- **Inputs -> outputs:** bottles -> island unlocks; Garbage -> Trash shop; Rando currency -> Rando shop; Shimmer points (from weekly trials) -> Shimmer shop; AFK hours/Time Candy -> Fractal thresholds. Outputs: stamps, bribe set, talent books, % loot, Total Damage / Class EXP / Skill Efficiency / base stats, kitchen cost cut, +100 star talent points, ninja stealth. [C12][C16][C22][C26][C27]
- **Goals and Milestones:**

| Milestone | Threshold | Source |
|---|---|---|
| Island N unlocked | bottles >= cost (see catalogue) | [C3][C4] |
| Bottle bonus ladder | Omar quests 1-6 (+10% each), bribe +10, bundle +30, Trash upgrade +10 each | [C9] |
| Crystal mobs cap | 14 unclaimed days (13 days = 27 mobs is the peak) | [C19] |
| Fractal tiers (hours) | 24, 200, 750, 2500, 10k, 20k, 40k, 60k | [C26] |
| Shimmer shop | next level costs 1 + floor(level/divider) | [C22] |

- **Feeds / fed by:** Stamps (4 Trash stamps), Bribes (Bottle_Service, Art_of_the_Bail, Random_Garbage), Quests (Omar Da Ogar, Yum Yum Desert), Sailing artifact Shim Lantern (x2..x4 shimmer), Kitchen/Cooking (-30% costs), Star Talent points, Sneaking (stealth), Sailing (artifact find chance), Damage/Class EXP/Efficiency totals, Time Candy (Crystal drops; Fractal and Omar consume it), Random Events (Rando island, Random_Garbage bribe). [C9][C16][C25][C27][C38]
- **Per-session actions:** claim daily bottles; spend bottles on the next island; visit Crystal before 14 unclaimed days pass (do not wait for the cap, since mobs fall from 27 to 15); collect Trash (cap 100 per collection); check the current Shimmer trial and bank points; feed Fractal when candy is spare. Idle/capped state: Crystal at 13-14 days, Trash at 100 pending, unspent Shimmer points. [C13][C14][C19][C23]
- **AFK Setup implications:** none per character. The Fractal hours counter rises with AFK time/candy; Fishing chars benefit from Seasalt fish later. [C28][C21]
- **Min-max by stage:** see section below.
- **Common mistakes:** letting Crystal days hit 14; buying one-time Trash items before the garbage-gain and bottle-gain upgrades; unlocking Fractal first although it only pays from late game; ignoring Rando's talent book (guide timing disputed, C33). [C19][C31][C33][C30]
- **Save and Toolbox fields:** see catalogue. Toolbox section is `account.islands` (`getIslands`, wired at `parsers/index.ts#L314`). ActiveOn lists `islands` as a pass-through field has a registry entry, the `sys-islands` sprite and two KB facts (`systems.facts.yaml`, `talents.facts.yaml`); no detectors or page. **Disputed** (see C36). [C36]
- **Sources:** inline per claim; all verified 2026-10-19.

## Mechanics catalogue

1. **Island unlock state** - letters `_`,a,b,c,d,e for islands 0..5 in `OLA[169]`; unlocked = letter present; count = string length. Path: `account.islands.list[i].unlocked`, `islandsUnlocked`. [C2]
2. **First-island cost (tier 0)** - Trash 4, Rando 12, Crystal 20, Seasalt 28, Shimmer 40, Fractal 52 bottles (the "+pre multiplier" at tier 0 is 0). `account.islands.list[i].cost`. [C3]
3. **Later island cost** - base + m(n) where n = islands already unlocked: m = 15, 45, 100, 200, 500, then 500 (n=6, inferred). Bases: Trash 10, Rando 12, Crystal 15, Seasalt 50, Shimmer 25, Fractal 70. Order-independent after the first pick. [C4][C5]
4. **Cost disagreement** - idleon.wiki lists a different cost table (same first column as the code bases, different later columns). Confidence L on the middle tiers. [C6]
5. **Bottles held** - `OLA[162]` -> `islands.bottles`. [C11]
6. **Bottles per day** - floor(4 x (1 + B/100)), B = bribe Bottle_Service (+10) + 10 x `OLA[164]` + 10 x Omar quests done (max 6) + 30 if bundle bun_p. `islands.bottlesPerDay`. [C8][C9]
7. **Omar Da Ogar quests (6)** - each +10% bottles; items: 20k Thread; 24x1h+10x2h+5x4h Time Candy; 40k Sand Shark + 1 BobJoePickle; 250k Kraken + 1 BJP; 250k Fruitfly + 75k Worker Bee + 2 BJP; 1000 Shellfish. Path: `account.quests.Yum_Yum_Desert[Omar_Da_Ogar].npcQuests`. [C10]
8. **Trash currency and shop** - garbage in `OLA[161]`; prices 20, 40, 80, 300 (stamps Skelefish B47, Amplestample B32, Golden Sixes A38, Stat Wallstreet A39), 7x1.4^`OLA[163]` (+20% garbage gain), 135 (new bribe set), 25x1.5^`OLA[164]` (+10% bottle gain), 450 (Filthy Damage star talent book), 1500 (Trash Tuna nametag EquipmentNametag6b). `islands.list[0].shop`. [C12][C15][C17]
9. **Garbage per day** - 3 x bonus x floor(1.01 + 0.5 + min(days,70)/100 + `OLA[163]`/5); bonus = 0.25 + days (days < 14) else sqrt(8 x days); capped at 100 per collection; days AFK = `OLA[160]`. `trashPerDay`, `trashPerDaysAfk`. [C13][C14]
10. **Bribes tied to Trash** - Art of the Bail (99,999,999 coins) unlocks the next bribe set from the Garbage Tuna; Random_Garbage (8e12) makes Random Event bosses drop Garbage Piles; Bottle_Service (4e13) +10% bottles. [C16][C9]
11. **Rando island** - one guaranteed Random Event per week; shop: 5% loot, cost round(10x1.5^`OLA[166]`); 3% double boss, cost round(6x1.4^`OLA[167]`); Rando Event Looty book 200. `islands.list[1].shop`. [C18]
12. **Crystal island** - one unclaimed day per daily reset, max 14; mobs = ceil(1 + 2d) for d < 14 else ceil(sqrt(16d)); entering resets d to 0. `OLA[171]` -> `unclaimedDays`, `mobsWaiting`. [C19][C40]
13. **Crystal mob strength** - wiki: 2000x drop, 750x HP, 30000x EXP vs normal mobs. Drops Time Candy and class EXP. [C20][C38]
14. **Seasalt island** - fishing spots for Icefish, Shellfish, Jumbo Shrimp, Caulifish (World 6 equip/stamp materials). No state parsed beyond unlocked. [C21][C39]
15. **Shimmer weekly trial** - one of 22 trials, index `OLA[183]`; best DPS `OLA[172]`; points `OLA[173]`. Reward ceil(10 x min(4, sqrt(result/requirement))) for most trials (DPS and efficiency trials use log scales). [C23][C24]
16. **Shimmer shop** - 7 items with levels in `OLA[174..180]`: Base STR (div 12), AGI (12), WIS (12), LUK (10), Total DMG % (3), Class EXP % (4), Skill Eff % (5). Next-level cost 1 + floor(level/div). [C22]
17. **Shimmer multiplier** - `allShimmerBonus` = clamp(1 + Shim Lantern bonus, 1, 4). Applied to Total DMG (`OLA[178]`, damage.ts#L343), Class EXP (`OLA[179]`, character.ts#L2117), Skill Eff (`OLA[180]`, efficiency.ts#L197). [C25]
18. **Fractal island** - `OLA[184]` hours; 8 bonuses unlocked when hours >= cost: trophy chance 1/100000 per hr of Nothing AFK (24), 1.25x dungeon credits/flurbos (200), -30% kitchen upgrade costs (750), 1.20x sailing artifact chance (2500), +25% gold nuggets from Dirty Shovel (10k), +100 star talent points (20k), +2% ninja twin stealth per Sneaking LV (40k), a W7 bonus (60k). `islands.list[5].shop`. [C26][C27]
19. **Tome entry** - "DPS Record on Shimmer Island" is a Tome line (x1 20, x3 350). [C29]
20. **W5+ extension** - Sailing islands (path `account.sailing.islands`, `sailing.ts#L130`) are distinct; Shim Lantern (W5 artifact, 12000 base find chance) multiplies Shimmer; Fractal (2500 h tier) adds +20 artifact find chance (sailing.ts#L699-L700). [C37][C25][C27]
21. **W6/W7 extension** - Fractal "+2% stealth per Sneaking LV" feeds Sneaking (W6); Fractal's last tier is a W7 bonus not yet revealed in data. [C27]

22. **Other Toolbox consumers of island state** - FILTHY_DAMAGE talent: damage per power-of-10 Garbage (damage.ts#L742); Rando Event Looty talent: scaled by random events found (character.ts#L3328, `randoEventLooty * randomItemsFound`). [C41][C42]
23. **Rando shop levels** - 5% Loot (`OLA[166]`) and 3% Double boss (`OLA[167]`) are levelled purchases with rising cost. [C18][C43]
24. **Shimmer shop talent book** - the Shimmer shop also lists DUMMY_THICC_STATS, a talent book (source lens; stat effect not parsed in data checked). Confidence L. [C44]
25. **Shimmer trial list** - 22 trials (stat totals, per-stat, DPS by class tier, accuracy, defence, move speed, crit, giant mobs, HP, MP, dummy hits, mining/choppin/fishing/catching efficiency, guild GP); `OLA[183]` picks the weekly one, reward points feed `OLA[173]`. Rotation order beyond the index is not in Toolbox. [C23][C45]
26. **Crystal mob debuffs** - source lens: Crystal mobs carry 0.5x Def and 0.25x Atk debuffs. Confidence L (not rechecked in code). [C46]
27. **Seasalt fishing areas** - source lens: three fishing areas (not named in Toolbox). Confidence L. [C47]
28. **Bundle and bribe interplay** - bun_p (+30 bottles) and Random_Garbage (Random Event bosses drop Garbage) tie Trash and Rando to Random Events. [C9][C16][C48]
29. **Trash Tuna nametag** - EquipmentNametag6b tracked via the looty slab. Confidence M. [C49]

## Min-max by stage

- **W1 early/mid/late:** nothing; islands need Fishing 30 (W2). [C7]
- **W2 early:** unlock Trash first, then buy garbage-gain and bottle-gain upgrades before one-time items; do Omar quests as materials allow. [C30][C31][C9]
- **W2 mid:** Crystal for Time Candy and class EXP, claim before 14 days; Shimmer next, favour Skill Efficiency. [C30][C32][C19]
- **W2 late:** Seasalt (legendary fish), then Rando, buy the Rando Event Looty book (200). [C30][C33]
- **W3:** keep trials going; spend Shimmer points as they come. Tier 3-4 community view: Fractal still low priority because AFK time/candy has better uses. [C30]
- **W4:** Fractal kitchen cost cut (-30% at 750 h) matters once Cooking is active; star talent points at 20k h. [C27]
- **Cost-order note (derived):** under Toolbox constants only the first pick differs; Seasalt-first totals 1020 bottles, Trash-first 1036, so bottle cost is not the deciding factor (priority is about the rewards). [C35]
