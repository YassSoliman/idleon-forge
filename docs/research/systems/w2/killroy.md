## Killroy's Slaughterhouse

- **What it is:** a weekly, time-limited kill challenge. Killroy (YumYum Grotto, W2) sends one character of a class chosen for the week into a copy of a normal monster map; kills drop Killroy skulls (currency for the Skull Shop), talent-point ribbons and, later, Dungeon Credits and Pearls (wiki-tier, confidence M; the parser only shows OLA[110]/[111] as upgrade levels, descriptions "Mobs can drop Dungeon Credits / Pearls now", H). After each run you pick one permanent run upgrade. [C1] [C2] [C3] (confidence M: wiki, unverifiable in code; the Dungeon Credit/Pearl unlock is recorded twice, see M6)
- **Unlocks:** room 1 from W2 (YumYum Grotto). Room 2 needs World 4 accessible (World 3 finished); room 3 additionally needs the 1% Skull Shop roll (OLA[227] = 1) and also requires that same gate. Resolved in contradictions-1 [X3] from N.js (Killroy scene init @4337500-4338300): `if (GenINFO[58] >= 4) { rooms = 2; if (OLA[227] == 1) rooms = 3 }`, else 1 room. `GenINFO[58]` is the highest unlocked world (2..7 from `KillsLeft2Advance[0/50/100/150/200/250][0] <= 0`, or Windwalker/Tesseract portal checks @5536145), so room 2 (and 3) need World 4 to be accessible, i.e. World 3 finished; the wiki ("after reaching World 4") and ActiveOn's World 3 gate are the same event. Toolbox `getKillRoy` (misc.ts#L1592-1593) ignores the gate and always counts 2 rooms, so on an account that has not reached W4 Toolbox over-counts rooms (Toolbox gap). Proxy caveat: Toolbox/ActiveOn `finishedWorlds.World3` = a character spoke to the W3 gatekeeper (Carpenter Cardinal, quests.ts#L29-L44), the game uses the portal kill quota; they can differ briefly. Confidence H (game gate), M (proxy equivalence). Skull Shop items 11-15 gate on Rift progress, 16-20 on the Plastic Basin (wiki only; no such gating in the Toolbox parser, confidence L). [C4] [C5] [C6] [C7] [X3]
- **Scope:** account-wide currency, upgrades and Skull Shop levels; each run is done by one character that must match the room's class (Beginner line, Warrior, Archer, Mage). Kills/records are account-wide (`KRbest`). [C8] [C9]
- **Inputs -> outputs:** In: one character-run per open room per account week (about 100-260 s each), optional 400 gems for a manual reset (wiki only, L). Out: skulls (spent in the Skull Shop, wiped weekly), talent points, Dungeon Credits, Pearls, Killroy Prime kill totals (permanent Total Damage multiplier up to x3, Rift/Equinox/Research/Tome counters). [C10] [C11] [C12] [C13]
- **Goals and Milestones:** see tables below (shop breakpoints, Prime damage, Equinox challenges, rooms).
- **Feeds / fed by:** Fed by (confidence H for Armory/Shades, M for the rest): Royal Armory "Weekly Skull Stipend" (W-armory, +2 starting skulls/level), Meritocracy (skull drop chance: M, formula is wiki-only), Equinox "Shades of K" (extra post-run choice), Equinox Dream cloud. Feeds: Arcade balls, Library checkouts, Refinery, Pets (mob eggs), Cooking (ladles), Time candy, Crystal mobs, Dungeon Loot Dice, Pearls (Skill/Class XP), Sailing artifact find (W5), Gaming nugget (W5), Farming crop evolution (W6), Summoning (stone trials stored in `KRbest`, W6), Gallery grade, Masterclass drops, W7 skill EXP, coral gain (W7), Total Damage (all worlds), Equinox bar fill and challenges, Research Killroy Prime total. [C14] [C15] [C16] [C17] [C18] [C19]
- **Per-session actions:** when the account week has not been run: run each open room (names the class and best character; Toolbox alert "Killroy available"); after the run choose a permanent upgrade; spend ALL skulls before the account week ends (arcade packs first, then the chosen permanent items). Idle/wasted state: skulls > 0 close to week end, an open room whose class no character has, monsters in the current rooms under 100 Killroy kills while Equinox 100-kill goals are open. [C20] [C21] [C22] [C23]
- **AFK Setup implications:** none (active play only, 2-5 minutes per room). Needs a character of the room's class; use a non-pusher character when another of the class exists. [C24]
- **Min-max by stage:** see below.
- **Common mistakes:** hoarding skulls past the weekly reset; spreading skulls across low-value permanent items (pet eggs, ladles, nuggets) before the 3rd-room roll and arcade balls; forgetting to buy at least 1 point of each run upgrade; running with a weak class (AoE matters); not tracking which monsters are under 100 kills for Equinox. [C25] [C26]
- **Save and Toolbox fields:** see Mechanics catalogue. Parsed output `account.killroy` = `{list, permanentUpgrades, totalKills, totalDamageMulti, rooms, killRoyClasses, upgrades, skulls}`; ActiveOn reads `account.killroy` (slots) = `{roomsOpen, doneCode, roomClasses, skulls, arcadePacksBought}`. [C27]
- **Sprites:** `sys-killroy` is needed if absent from `apps/activeon/src/art/sprites/grids/systems.ts` (not verified in this dossier). For a dedicated Killroy view, new sprites: Killroy skull (currency), three room-class badges (reuse class sprites), a ribbon (talent point), 10 Skull Shop item icons (reuse existing time candy/pearl/arcade ball/library/refinery/egg/ladle sprites; new: dice, crystal mob candy, nugget, Armory stipend), six run-upgrade icons (timer, talent, skull, respawn, dungeon credit, pearl). [C28]

## Mechanics catalogue

M1. **Room availability (H, resolved).** Game: rooms = 1 until `GenINFO[58] >= 4`, then 2, then 3 if OLA[227] === 1. Toolbox `getKillRoy` counts 3 if OLA[227] === 1 else 2 with no world check (over-counts before W4). ActiveOn's `readKillroy` (World 3 finished -> 2, then 3 with the roll) matches the game. Resolved in contradictions-1 [X3] from N.js (Killroy scene init @4337500-4338300): `if (GenINFO[58] >= 4) { rooms = 2; if (OLA[227] == 1) rooms = 3 }`, else 1 room. `GenINFO[58]` is the highest unlocked world (2..7 from `KillsLeft2Advance[0/50/100/150/200/250][0] <= 0`, or Windwalker/Tesseract portal checks @5536145), so room 2 (and 3) need World 4 to be accessible, i.e. World 3 finished; the wiki ("after reaching World 4") and ActiveOn's World 3 gate are the same event. Toolbox `getKillRoy` (misc.ts#L1592-1593) ignores the gate and always counts 2 rooms, so on an account that has not reached W4 Toolbox over-counts rooms (Toolbox gap). Proxy caveat: Toolbox/ActiveOn `finishedWorlds.World3` = a character spoke to the W3 gatekeeper (Carpenter Cardinal, quests.ts#L29-L44), the game uses the portal kill quota; they can differ briefly. Confidence H (game gate), M (proxy equivalence). Toolbox dashboard alert additionally gates the partial-run alert on World 3 (account.js L644-650). [C4] [C5] [C29] [X3]

M2. **Rooms-done code OLA[113].** Per-digit code: entering room r adds `r*10^(r-1)`; room r done when the decimal string contains digit r. Valid: 1, 20, 21, 300, 301, 321. Toolbox's skip list handles only 1, 21, 321 (skips rooms 0 / 0,1 / 0,1,2); alert fires when OLA[113] === 0 or `< 321` (3 rooms) / `< 21` (2 rooms) after World 3. Reset weekly (H code, M for the digit encoding, which the game-data lens could not verify beyond skipConditions 1/21/321). Path: `misc.ts` `getKillRoyClasses` L1864-1876; M20 spec F-c (N.js @4314131). [C30] [C31]

M3. **Room class roll.** `baseSeed = floor((GlobalTime + round(ShopRestock + 86400*OLA[39])) / 604800)`; per room i: `seed = round(baseSeed + iteration + 50*i + serverVars.KillroySwap)`, `r = LavaRand(seed).rand()`, `classIndex = clamp(ceil(3r - floor(i/2)), 0, 3)` (0 Beginner, 1 Warrior, 2 Archer, 3 Mage). Derived (assuming rand in [0,1)): rooms 1-2 are ~33% each Warrior/Archer/Mage (Beginner only at r = 0); room 3 is Beginner/Warrior/Archer (~33% each), never Mage. `getKillroySchedule` projects 20 weeks ahead (`iteration` 0..19). Confidence H (verified `misc.ts` L1853-1913; room 3 never Mage confirmed). **Missed mechanic, now added:** the server var `serverVars.KillroySwap` is added to every room seed (`misc.ts` L1880, L1887; type `generated-firebase-types.ts` L857), so a server-side change shifts all rooms; the adapter must pass serverVars or schedules will be wrong when it is non-zero (H). Path: `misc.ts` L1853-1895. [C32] [C33]

M4. **Room monster roll.** `random = floor(1000*rand)` (same seed). If `random < 300` or room 0: pool `randomList[68+i]` (room 0 = W1 maps; room 1 = W2; room 2 = W3). Else: `random < 400` and a character has cleared map 200 (W5 town) -> W5 pool (`randomList[72]`); `random < 500` and `summoning.summoningStuff[2] >= 4` -> W6 spirit pool (`randomList[99]`); else pool `randomList[69+i]` (room 1 = W3, room 2 = W4). Map = pool[random mod pool.length]. Confidence H. Pools: W1 15 maps, W2 11, W3 13, W4 13, W5 13, W6 14 (`V/data/website-data/randomList.json`). Path: `misc.ts` L1877-1913. [C34] [C35]

M5. **Run timer.** 100 s + 1 s per level of the "+1 Second Timer" upgrade (OLA[106]). Spawn cutoff 250 s and 300 spawn waves confirmed (source lens, M); the 100 s base is H (parser); "~4:08" and "~160 levels fills 260 s" are community and unverifiable (L). [C36] [C37]

M6. **Run upgrades (permanent, one chosen after each run).** OLA[106] Timer (+1 s); OLA[107] Talent Drops (talent point chance `(1+0.05L)/max(10, T^2+10(T+1))`, T = talent points already got from Killroy; unlock 2 runs); OLA[108] Bonus Skulls (chance `(1+M/100)*min(0.25, 0.25*(1+L/100)*max(0.1, 1-0.995*K/(K+50)))`, L level, K kills in the run, M Meritocracy; unlock 16 runs); OLA[109] Faster Respawn (36 runs); OLA[110] Dungeon Drops (credits chance `0.01*(1+L/100)`; 64 runs); OLA[111] Pearl Drops (`0.002*(1+L/100)`; 100 runs). Level caps are not in the parser (no cap known, L). Costs: none in parser (the choice is the cost). Unlock-by-run counts and formulas are wiki-only and unverifiable in Toolbox (M for 2/16/36 runs, L for the exact formulas). **Sources conflict on Dungeon Credit / Pearl unlock** (Disputed): wiki gates by completed runs (64 for Dungeon Drops, 100 for Pearl Drops); gameslikefinder (tier 4) says a W3 Equinox upgrade unlocks them; the parser exposes OLA[110]/[111] only as upgrade levels. Confidence L on either. Missed mechanics (wiki, M/L): Meritocracy multiplies the skull drop chance (the `M` term above; Meritocracy bonus index 10 is the Total Damage-related one in `character.ts` L1644, so the skull-chance index is unverified); Talent point ribbon pity: the chance falls as T grows, with T a per-account counter (formula above, M); Faster Respawn (OLA[109]): +1% per level chance of another mob in each of the 300 spawn waves (wiki, L); Dungeon Credit "Flurbo Edition" and Divinity Pearl sub-drops exist (wiki, L); whether an airhorn/gem reset clears rooms only or also skulls is unspecified (L). Path: `misc.ts` L1596-1625 (`upgrades`). [C38] [C39] [C40]

M9. **Diminishing-return curves.** `bonus = base + scale * L/(decay + L)` with L the OLA level (one level per purchase). Artifact: base 1, scale 1, decay 300 (cap 2.00x). Crop Evolution: 1, 9, 300 (cap 10x). Jade: 1, 2, 300 (cap 3x). Gallery: 0, 10, 200 (cap +10, shown +0.10x). Masterclass: 1, 1.3, 200 (cap 2.3x). W7 EXP: 1, 0.8, 150 (cap 1.8x). Coral: 0, 25, 250 (cap +25%). Mystery: 1, 2, 200 (cap 3x). Confidence H for the curves (misc.ts and `permanentUpgradeCapMap` confirmed). Reaching p% of the cap needs `ceil(decay*p/(100-p))` levels: 50% = decay; 75% = 3*decay; 90% = 9*decay; 95% = 19*decay; 99% = 99*decay. The cap is never reached. Path: `misc.ts` `getKillRoyShopBonus` L1813-1841; `V/data/website-data/wikiTables.json` `killroyBonusCurves`; `permanentUpgradeCapMap` L1658-1667. [C46] [C47]

## Min-max by stage

- **W2 early/mid (room 1 only):** run the room every week with the listed class (Beginner line, Warrior, Archer or Mage per roll). Put 1 point in each run upgrade as they unlock, then Timer toward ~160. Spend skulls on Arcade balls (4 skulls = 10 balls, up to 50 packs/week) first. [C58] [C59]
- **W2 late / W3 (room 2 after World 3):** keep both rooms; run upgrade order: 1 point in all six, Timer to level 160, then Bonus Skulls and Respawn equally (Respawn first if an Equinox challenge blocks). Shop: roll the 3rd-room item (cost 4, 1%; expected about 100 buys = about 400 skulls) once weekly basics are bought; then Arcade balls, time candy. [C58] [C59] [C60]
- **W3 late / W4:** community tier ranks: S = 3rd room roll, Arcade balls (gems), Gallery grade (target 0.08-0.09x, the cap is +0.10x, so about 80-90% of the cap, roughly 800-1800 levels at decay 200); A = time candy, W7 EXP, coral gain, Refinery cycle; B = Masterclass drops, library; C = artifact/crop; F = pet eggs, ladles, nuggets. This ranking is built for W7-capable accounts; for W1-4 the unlocks (Rift, Plastic Basin) gate shop items 11-20, so the practical W4 order is 3rd room -> Arcade -> time candy -> Refinery/Library. Prime kills raise damage permanently (floor(K^0.4)): every run improves the best-per-monster score. [C49] [C58] [C61]
- **Each stage:** pick the class-appropriate AoE character (Barbarian before World 3, then Squire for Warrior; Bowman until Beast Master for Archer; Shaman for Mage; any of Journeyman/Maestro/Void Walker for Beginner); do not use the AFK pusher unless it is the only one of the class. [C24] [C62]
- **Late game (W5+ outline):** shop curves become the target (breakpoint table), Weekly Skull Stipend in the Armory (+2 skulls/level), Prime kills for damage and Research, Equinox kill challenges.
- **Disagreement flagged (confidence M):** community puts W7 EXP and Coral above Artifact/Crop (A vs C), consistent with higher caps but W5+; no source gives a numeric W1-4 order past the three rules above (confidence M). [C61]
